# Repository Analysis Checklist

## Issue
- [ ] Observed behavior identified.
- [ ] Expected behavior identified.
- [ ] Errors and relevant symbols extracted.
- [ ] Constraints identified.

## Search
- [ ] Distinctive search terms extracted.
- [ ] Semantic search used where appropriate.
- [ ] Multiple candidates considered when necessary.

## Code
- [ ] Candidate files identified.
- [ ] Candidate symbols identified.
- [ ] Callers/dependencies inspected.
- [ ] Subgraph used only when necessary.

## Tests
- [ ] Relevant tests located.
- [ ] Expected behavior inspected.
- [ ] Edge cases identified.
- [ ] Validation commands identified.

## Hypothesis
- [ ] Likely root cause identified.
- [ ] Required behavior change identified.
- [ ] Files requiring modification identified.
- [ ] Validation plan defined.

## Before editing
- [ ] Evidence is sufficient.
- [ ] Scope is understood.
- [ ] Proposed change is minimal.
